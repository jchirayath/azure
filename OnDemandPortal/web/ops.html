⏰ Scheduled start / stop

Days = ISO weekdays, Mon=1…Sun=7 (e.g. 1-5 or 1,3,5). Inside the window the VM is resumed; outside it the VM is deallocated (a keep-running hold overrides stop). A scheduled start only resumes an existing VM — it never deploys a new one. Checked every 15 min.
